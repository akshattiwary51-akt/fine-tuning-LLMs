# Requirements for running this project in a hosted notebook (Google Colab,
# Kaggle Notebooks) instead of via Poetry locally. See docs/COLAB.md.
#
# Deliberately does NOT include torch/torchvision/torchaudio: Colab and Kaggle
# both preinstall a PyTorch build already matched to their GPU driver/CUDA
# version. Reinstalling a different torch build (e.g. pyproject.toml's pinned
# cu124 wheel) risks breaking that match and is unnecessary — the preinstalled
# torch is what you want. If `import torch; torch.cuda.is_available()` prints
# False after installing this file, the fix is enabling a GPU runtime, not
# reinstalling torch (see docs/COLAB.md step 1).
#
# Versions are intentionally loose (matching pyproject.toml's own ranges)
# rather than exact-pinned, since notebook environments change frequently and
# exact pins here would go stale fast; pyproject.toml + poetry.lock remain the
# source of truth for exact, reproducible local/production installs.
